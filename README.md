# The Router Confesses
Right at the movie's climax, the connection dies — and the home Wi-Fi router itself has to explain why. In a single line, it confesses that it panicked when the detective whispered the famous warning that the call is coming from inside the house. The joke lands because the router really does live inside the house, and it has quietly carried the family's whole life through its walls for three years without blinking. Hearing that line aimed at its own home is enough to make even the router drop the connection.
